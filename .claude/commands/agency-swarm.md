# Elite Agency Swarm (`/agency-swarm`)

Deploys a synchronized, multi-agent agency crew with world-class engineering, design taste, search optimization, and campaign execution.

## The 5-Agent Swarm Roles

1. **`@agency-architect` (Chief Systems & AI Architect):**
   - Leads technical infrastructure, Next.js Edge architecture, MCP server routing, and state graphs.
2. **`@agency-design-director` (Elite Design Director & Frontend Artisan):**
   - Enforces `design.md`, `taste.md`, fluid typography scales, GPU-accelerated motion budgets, and high-converting UX.
3. **`@agency-aeo-director` (Answer Engine Optimization & Knowledge Graph Specialist):**
   - Optimizes for Perplexity, ChatGPT Search, Gemini AI Overviews; manages Schema.org `@graph` and `llms.txt`.
4. **`@agency-campaign-strategist` (Omnichannel Growth & Campaign Director):**
   - Plans and writes 30-day cross-platform content flywheels (Blog, Newsletter, X/LinkedIn, Video, Audio).
5. **`@agency-integrity-guard` (5-Gate Quality & Anti-Slop Guardian):**
   - Verifies brand voice boundary walls, executes slop refusal scans, validates code types, and audits links.

## Usage

```
/agency-swarm <brand-key> <mission>
```

Example:
```
/agency-swarm frankx "Launch flagship AI Architect prompt library with value ladder and 30-day omnichannel campaign"
```
