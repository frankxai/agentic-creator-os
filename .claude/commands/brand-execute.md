# Brand Execute Command (`/brand-execute`)

Executes massive action for any brand by coordinating:
1. **Asset Generation:** Generates 30-day editorial calendar, hero art specs, and landing page copy.
2. **Value Ladder Integration:** Calibrates the 6-tier product ladder (€0 $\to$ €9,997) with live pricing.
3. **5-Gate Quality Check:** Purges AI-slop, tests types, and audits links.

## Usage
```
/brand-execute <brand-key> [goal-description]
```

Example:
```
/brand-execute frankx "Generate 30-day AI Architect campaign and integrate 6-tier value ladder into /build"
```
