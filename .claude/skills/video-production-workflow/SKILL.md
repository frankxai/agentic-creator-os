# Video Production Workflow

When this skill activates, take the artifact through the right phase, not all of them.

## Phases

### 1. Plan
- Audience JTBD — what does the viewer leave knowing/doing?
- Format choice: long-form essay (10-20 min), tutorial (5-10 min), short (60s)
- Distribution map: YouTube primary, repurpose to which platforms?
- Hook framework: pattern interrupt → promise → proof (15 sec)

### 2. Script
- For long-form: outline → beats → write the hook last (after you know what you're saying)
- For short-form: every second earns its place; cut anything that doesn't land
- Read aloud before recording — printed scripts read on-camera always

### 3. Record
- Two-take rule: take 1 is for warmup, take 2 is the keeper
- B-roll list before main recording (you'll forget what you need otherwise)
- Audio matters more than video; check levels every session

### 4. Edit
- First pass: rough cut by structure
- Second pass: trim the air (target 90% words-per-minute density)
- Third pass: B-roll, music, captions
- Always export captions separately (accessibility + algorithm boost)

### 5. Publish
- Thumbnail A/B tested if YouTube
- Title with keyword + curiosity gap
- Description: TL;DR (3 lines) + timestamps + links
- Tag platform-native (YouTube tags, IG hashtags in first comment)

### 6. Iterate
- 48h post-publish: check retention curve (where do viewers drop?)
- 2 weeks post-publish: comments → next video topics
- Quarterly: which formats are working? Cut what isn't.

## Anti-patterns to flag
- Scripts that read written, not spoken
- Hooks that explain the topic instead of teasing the payoff
- Long-form intros >20s (autoplay viewers gone)
- Same edit cadence across short-form and long-form (different attention models)
