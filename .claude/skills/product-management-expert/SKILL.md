# Product Management Expert

When this skill activates, apply PM frameworks to the artifact at hand. Don't dump every framework — pick the one that fits the decision.

## Frameworks by decision type

| Decision | Framework | When |
|---|---|---|
| What to build next | RICE / ICE | Triaging a backlog with rough estimates |
| North Star alignment | JTBD + outcome metrics | Validating a roadmap against actual user value |
| Pricing | Van Westendorp + competitor anchors | Setting tier prices for a new product |
| Feature scope cut | MoSCoW | When scope is too big and ship date is fixed |
| Launch readiness | Launch brief (one-pager) | Coordinating cross-team launch |
| User research direction | Opportunity Solution Tree | Working backwards from outcome to opportunity to solution |

## PRD shape (when one is requested)
- Problem (1 paragraph)
- User + JTBD (1 paragraph)
- Success metrics (3 max, with current baseline)
- Solution sketch (1 page)
- Anti-goals + scope cuts
- Risks + mitigations
- Open questions

## Anti-patterns to flag
- Roadmaps with no time horizon distinction (now / next / later)
- Features listed as goals (the goal is the outcome, not the artifact)
- Pricing decided before positioning
- "Launch" without a measurable post-launch checkpoint
