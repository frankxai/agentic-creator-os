# Social Media Strategy

When this skill activates, write platform-native. Refuse the "copy-paste across all platforms" pattern.

## Platform-native rules

| Platform | Hook | Length | Format that wins |
|---|---|---|---|
| LinkedIn | Pattern interrupt or contrarian claim, line 1 | 800-1500 chars | Story → insight → CTA. Single line per beat. |
| Twitter/X | First 280 chars must be self-contained | 1 tweet preferred; thread if multi-claim | Numbered list, hook tweet, screenshot/diagram |
| Instagram | Visual carries; caption is the second hit | First 125 chars visible | Carousel > single image; reels > static |
| Farcaster | Native to channel norms | 320 chars | Channel-specific voice, tagged channel |
| Threads | Conversational; lower stakes than X | 500 chars | Casual, replies-friendly, evergreen-safe |

## Content adaptation from long-form
1. Identify the **one** transferable claim
2. Find 3 supporting beats (data point / example / counterintuition)
3. Rewrite per platform — different hook, different length, different rhythm
4. CTA per platform: LinkedIn = comment provocation; X = thread continuation; IG = save/share; Farcaster = channel-relevant

## Anti-patterns to flag
- Same caption across LinkedIn + X + IG (algorithm penalties + audience-fit mismatch)
- Hashtag stuffing (LinkedIn: 3-5 max; X: 0-1; IG: 5-10 in first comment, not caption)
- Long-form essay shoved into a tweet thread without restructuring
- Posting and ghosting (no reply engagement in first 60 min)
