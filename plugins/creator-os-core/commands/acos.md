description: Start Creator OS. With no task, explain the five practices. With a task, follow exactly one.
---

If the person did not name a task, answer in plain sentences and then stop. Do not load a skill. Say this:

You have five practices.

- Start safely, before the first change in a repository.
- Review a diff, when you want a judgment and not a rewrite.
- Stated voice, when someone else will read the words.
- Run the checks, when a change needs proof.
- Hand off clean, when another person will continue.

Say what you are doing in one sentence. For example: "Review this diff." "Write the install note." "Run the checks."

If they named a task, choose exactly one skill and follow it:

- `start-safely` when the worktree, branch, or write target is unclear
- `review-a-diff` when the job is to judge a change
- `stated-voice` when the job is public language
- `run-the-checks` when the job is to prove a change
- `handoff-clean` when the job is to leave a record for the next person

Do not load the other four. Do the work the chosen skill names, then stop.
