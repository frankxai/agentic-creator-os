# Stated voice

1. Name the reader and the decision this text helps them make.
2. Put the useful fact in the first sentence.
3. Use one claim per sentence. Put the evidence in the next sentence.
4. Use the words the product already uses.
5. Do not invent a count, a date, a price, or a review score. If it is unknown, say so.
